The brief asks for one funny single-line developer excuse, under 200 characters.

## The entry

> Prod isn't broken — my 2 a.m. 'temporary' fix just passed its probation and is now permanent infrastructure.

## How the program works

`main.ts` runs on Node 22 using only the standard library, with no network access at all. It writes the excuse to `/output/entry.txt`. Because there is no randomness and no outside input, the file it produces is identical on every run.
